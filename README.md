# KATA-MACHINA

A cli tool to practice DSA (in go)

The `dsa.config.json` file contains all the configuration for generating the DSA you want to practice.

Commands for the CLI 

- `gen` - generates a new dir with a list of dsa files with their initial code (as per the config file).
- `test` - by default it will run the test for the latest dsa dir created or you can pass the dir name for which you want to run the tests for.
